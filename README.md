# 🪐 3D Planetary Learning Studio

An interactive 3D spatial learning platform combining real-time planetary dynamics powered by **Three.js** and **WebGL** with dynamic educational intelligence using the **Gemini 1.5 API** in Google AI Studio.

<Image src="image_agent_tag_17049072145841295730" alt="3D planetary visualizer with interactive orbital paths and AI study modules" caption="Interactive 3D planetary rendering with Gemini AI integrations" />

---

## ✨ Key Features

* **3D Planetary Engine:** Real-time spatial rendering of planetary bodies, orbital mechanics, and dynamic texture maps using Three.js.
* **Gemini 1.5 AI Integration:** Generates dynamic study cards, active recall questions, and spatial mnemonics directly based on the selected planetary target.
* **5 Interactive Learning Modes:** 
  1. 3D Spatial Mind Map
  2. Concept Flowcharts
  3. AI-Generated Mnemonics
  4. Active Recall Flashcards
  5. ELI5 (Explain Like I'm 5) Summaries
* **Smooth Camera Controls:** Cinematic focus switching and 360° inspection using custom `OrbitControls` smooth damping.
* **Custom GLSL Atmosphere Shaders:** Atmospheric rim lighting and glow effects for realistic celestial visual fidelity.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
